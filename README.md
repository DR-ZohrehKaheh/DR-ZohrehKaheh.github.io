# Dr Zohreh Kaheh — research website

Personal research website: **https://dr-zohrehkaheh.github.io/**

Static HTML and CSS, hosted with GitHub Pages. No package installation, build service, analytics or paid domain is required.

## Content

- `index.html`: profile, research themes, five software projects, selected publications, background, teaching and contact.
- `styles.css`: responsive layout, keyboard focus, reduced-motion and print styles.
- `sources.html`: content sources and attribution notes.
- `sitemap.xml`, `robots.txt`: crawler discovery.
- `favicon.svg`, `404.html`, `.nojekyll`: icon, error page and static hosting.

## GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**. The canonical site URL is `https://dr-zohrehkaheh.github.io/`.

## Editing

Edit content in `index.html`. Preserve collaborator credits, citation author order, DOI types and project limitations. Avoid asserting a current institutional appointment. Update the review date in `sources.html`, `dateModified` in the structured data, and `lastmod` in `sitemap.xml` after substantive changes.

Content sources are linked in `sources.html`. A 2024 journal issue citation is used for the distributed-procurement article, with its separate 2022 archive date noted explicitly.

## Search discovery

The site includes a descriptive title and description, canonical URL, sitemap, robots file, crawlable HTML, and ProfilePage/Person structured data. Link this website from public professional profiles. After deployment, the owner can verify a URL-prefix property in Google Search Console and submit `sitemap.xml`. No Search Console verification token is included until provided by the verified owner. These measures do not guarantee indexing or rankings.

Official guidance:

- https://docs.github.com/en/pages/quickstart
- https://developers.google.com/search/docs/fundamentals/seo-starter-guide
