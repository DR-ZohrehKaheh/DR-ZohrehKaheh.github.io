Citation, attribution & reuse

Software DOIs identify archived snapshots. Use each repository’s citation metadata to preserve author order, and include the commit identifier when citing later changes. A software DOI is separate from a related publication DOI.

These public repositories have no repository-wide software reuse licence. Read their rights statements before reuse. Raw datasets and trained model binaries are excluded. Repository documentation describes methods, contributor roles and the scope of validation.
